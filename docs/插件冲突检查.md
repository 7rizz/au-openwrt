# 插件冲突检查（2026-10-27）

> 每次加功能都容易撞车。这里记录「查过哪些组合、修了什么、还剩什么要注意」。

## 一、已处理的冲突

| # | 冲突 | 不处理的后果 | 处理方式 |
| --- | --- | --- | --- |
| 1 | **mwan3 ↔ UA 引擎** | 两者抢同一套 `fwmark` / `ip rule`，TPROXY 整段失效（表现为「UA 没改」） | `99-personal` 开机 `stop` + `disable` mwan3；要用多拨先 `ua-engine off` |
| 2 | **UA3F ↔ UA2F** | 两个引擎同时接管出站流量，互相抢包 | 互斥：`ua-engine-web` 启动一个时自动停另一个并取消自启；`99-personal` 只启 UA3F |
| 3 | **UA3F 的 TTL ↔ UA2F 的 TTL 表** | 两张表都挂 `postrouting priority mangle`，同优先级；一个设 128 一个设 64 → 最终 TTL 看创建顺序，可能变成 64 | ① 切到 UA3F 时删掉 `ip ua2f_ttl`；② UA3F 运行中，UA2F 面板拒绝再插 TTL；③ 开机时 `ua2f-ttl` 检测到 UA3F 就跳过 |
| 4 | **菜单 order 撞号** | 「WAN MAC 工具」和「顺枫公寓自动登录」都是 60，排序不稳定 | WAN MAC 改 59 |
| 5 | **两套自动登录同时开** | netcheck 与 drcomauth 各自循环登录，互相抢 | 两套**都默认关闭**，只开一个（见下表说明） |

## 二、查过、确认不冲突

| 组合 | 结论 | 理由 |
| --- | --- | --- |
| UA3F ↔ 自动登录（netcheck / drcomauth） | 不冲突 | `auth.sh` / `drcom-auth` 只**读**网卡信息（`ip link`、`ip route`），不改网络、不加规则 |
| UA3F ↔ 认证门户探测 | 不冲突 | `portal-probe` 只 `curl` 探测门户，不碰防火墙 |
| UA3F ↔ ttyd / 自定义命令 | 不冲突 | 都是 LAN 侧服务，TPROXY 只接管 WAN 出站 |
| UA3F ↔ dnsmasq | 不冲突 | dnsmasq 只管 DNS/DHCP，编译选项是 `no-conntrack no-nftset` |
| iptables 系 ↔ nft 系 | 不冲突 | UA3F 用 nft（`kmod-nft-tproxy`），UA2F 用 NFQUEUE；互不清表 |
| Argon 主题 ↔ 自建页面样式 | 不冲突 | 自建 CSS 全部 scope 在 `.au-page` / `.u2` / `.ua-engine-page` 下，不污染全局 |
| crashlog ↔ 系统日志 | 不冲突 | 只读 `logread`，只写 `/root/crash.log` |
| `luci-compat` ↔ 自建 Lua CBI | **必须共存** | UA3F 的设置页是 Lua CBI，删了 luci-compat 页面直接 404 |

## 三、不是冲突，但会互相影响

1. **UA3F 会改写自动登录请求的 UA**。登录表单一般不看 UA，但万一某天登录失败：先 `ua-engine off` 试一次，能通就说明是 UA 改写导致，再回来找我加排除规则。
2. **conntrack 上限**：TPROXY 下连接数比普通路由高，已从 16384 抬到 32768（`/etc/sysctl.d/10-conntrack.conf`）。
3. **两个 CGI 页面（连接设备 / WAN MAC）免鉴权**：只在 LAN 可用，**别把 80 端口映射到公网**。
4. **两套自动登录只能用一套**：顺枫（netcheck）和润泽（drcomauth）是不同学校的认证系统，同一个校园网只会用到其中一个。两个都开＝两个循环同时跑，互相踢下线。

## 四、自检方法

```sh
# TTL 规则只应该有一条（或 UA2F 那条，或 UA3F 那条，不能同时有）
nft list ruleset | grep -c 'ip ttl set'

# 两个引擎只能有一个在跑
pgrep -f /usr/bin/ua3f; pgrep -f /usr/bin/ua2f

# mwan3 必须是停的
/etc/init.d/mwan3 enabled && echo '!! mwan3 还开着'

# 两套自动登录不要同时 enabled
/etc/init.d/netcheck enabled && /etc/init.d/drcomauth enabled && echo '!! 两个登录都开着'
```
