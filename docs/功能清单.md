# 固件功能清单（v4.1）

> 这份清单是按 `device-files/` 里的实际文件和 `configs/` 里的两份 seed 逐项核对的，不是照抄 README。

### 1) UA3F 页面里具体能调什么

- **状态栏**：进程、版本、监听、运行时长、连接/改写计数
- **常规 → Settings**：Server Mode（HTTP / SOCKS5 / TPROXY / REDIRECT / NFQUEUE）、Bind、Port、Rewrite Mode（DIRECT / GLOBAL / RULE）、UA、UA 正则、部分替换
- **常规 → Rewrite Rules**：Header / Body / URL 重定向三类规则（域名、域名后缀、域名关键字、域名集合、IP-CIDR、源 IP、端口、Header 关键字、Header 正则、URL 正则、FINAL），动作有 REPLACE / REPLACE-REGEX / ADD / DELETE / DIRECT / DROP / REJECT / 302 / 307 / 重定向 Header
- **常规 → MitM Settings**：生成/导出 CA、证书口令、生效主机名、跳过校验
- **常规 → Desync Settings**：TCP 分片乱序（字节数/包数）、低 TTL 混淆注入、端口范围
- **常规 → L3 Rewriting**：TTL 值、删 TCP 时间戳、TCP 初始窗口、IPID 归零、QUIC 阻断、eBPF 加速（**MIPS32 用不了**）
- **常规 → Statistics**：命中统计
- **常规 → Log**：日志级别、行数、下载/清空

OpenClash、PassWall、SSR Plus、AdGuard Home、UPnP、动态 DNS。

## 二、网络菜单

- 接口（WAN/LAN/别名，PPPoE/静态/DHCP）
- 无线（radio0 2.4G / radio1 5G，已按下面默认值配好）
- DHCP/DNS（LAN 池 100~249，租期 12h；campus 用自带 dnsmasq，full 换 `dnsmasq-full`）
- 主机名、静态路由、防火墙（fw4/nftables，可开端口转发/规则/区域）
- 诊断（ping / traceroute / nslookup）
- **full 独有**：SQM 限速、mwan3 负载均衡（多拨）、网络唤醒

## 八、镜像里自带的内核模块与库（campus）

- 防火墙/IP 包处理：`iptables`、`iptables-mod-tproxy`、`-extra`、`-ipopt`、`-nfqueue`、`-conntrack-extra`
- nft/队列：`kmod-nft-queue`、`kmod-nft-tproxy`、`kmod-nf-conntrack-netlink`
- ipset：`ipset`、`kmod-ipset`、`kmod-ipt-ipset`
- 运行库：`ip-full`、`libatomic1`、`libgcc1`、`libmnl0`、`libnetfilter-queue1`、`libnetfilter-conntrack3`、`libnfnetlink0`
- 工具：`curl`、`ca-bundle`、`ca-certificates`、`tcpdump`、`htop`、`nano`、`openssh-sftp-server`
- 界面：Argon 主题（整包文件级塞进镜像，不靠 opkg）+ 6 个 `zh-cn` 词条

## 九、campus 与 full 的差别

| 类别 | campus（默认） | full |
| --- | --- | --- |
| 科学上网 | ❌ | OpenClash、PassWall、SSR Plus |
| 去广告/DNS | ❌ | AdGuard Home、`dnsmasq-full` |
| 网络增强 | ❌ | mwan3 多拨、SQM 限速、UPnP、动态 DNS、网络唤醒、定时重启 |
| 测速 | ❌ | `iperf3` |
| 防检测 | ✅ UA3F + UA2F（含 TTL/I 类重写） | 同左 |
| 安全证书 | `ca-bundle` + `ca-certificates`（自动登录用） | seed 里没显式写，由别的包的依赖带入 |

## 十、没有的东西（别找了）

- 没有 USB：U 盘挂载、4G 上网卡、打印机共享、Samba、Docker 统统无关
- 没有下载器（Transmission / qBittorrent / Aria2）
- campus 版没有 Frp / ZeroTier / MosDNS / SmartDNS（seed 里注释着，要用就去掉注释）
- 没有 nlbwmon 流量统计（上一版去掉的，需要的话在 seed 里加回来）
- 默认不跑任何代理客户端（科学上网三件套也不自启，用哪个开哪个）
