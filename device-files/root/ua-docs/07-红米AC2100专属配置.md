# 07 · 红米 AC2100（MT7621A）专属配置

> 你的场景：红米 AC2100 + OpenWrt，**多设备同时上网才被检测**。
> 这份文档把前面的通用方案收敛成这台机器上可以直接照抄的步骤。

---

## 一、先解读你的症状

"多设备同时上网才被检测"和"一接路由器就断"是两种不同的信号：

| 症状 | 说明 |
| --- | --- |
| **一接路由器、只连一台设备也断** | 多半是 **TTL 检测**——转发本身让 TTL 减了 1，跟几台设备无关 |
| **单设备正常，多设备同时上网才断** | 多半是 **UA / 设备指纹统计**——服务端发现同一账号下出现多种系统特征 |

你属于后者，所以**主攻目标是统一 UA**，同时用固定 TTL 兜底（防止学校其实也开了 TTL，
只是阈值宽松）。这也是本方案把 UA + TTL 一起做的原因。

---

## 二、AC2100 的硬件前提

| 项目 | 值 |
| --- | --- |
| 芯片 | MediaTek **MT7621A**（双核 MIPS 1004Kc @ 880MHz） |
| 内存 | 128 MB |
| 架构（用于选包） | **`mipsel_24kc`** |
| 性能评估 | 跑 UA2F 完全够用；日常带机 10 台以内没问题 |

**先确认你的 OpenWrt 版本**（决定下 `.ipk` 还是 `.apk`）：

```sh
. /etc/openwrt_release && echo "$DISTRIB_DESCRIPTION / $DISTRIB_RELEASE"
which opkg
which apk
opkg print-architecture 2>/dev/null || apk info --print-arch
```

- 看到 `opkg` → OpenWrt 24.10 及更老 → 下 **`.ipk`**
- 看到 `apk` → OpenWrt 25.12 及更新 → 下 **`.apk`**

架构那行应该包含 `mipsel_24kc`。

---

## 三、下载对应文件（已核实文件名）

**UA2F（推荐）**：[Releases 页面](https://github.com/SunBK201/UA2F/releases) 下载 mipsel_24kc 版本：

- `ua2f_3.7.0-r1_mipsel_24kc.ipk`  ← 24.10 及更老
- `ua2f-3.7.0-r1-mipsel_24kc.apk`  ← 25.12 及更新

**UA2F（备选）**：[Releases 页面](https://github.com/Zxilly/UA2F/releases)：

- `ua2f_4.10.2-1_mipsel_24kc-23.05.5.ipk`   ← OpenWrt 23.05.x
- `ua2f_4.10.2-r1_mipsel_24kc-24.10.0.ipk`  ← OpenWrt 24.10.x

> 文件名里的版本号对应 OpenWrt 版本，别下错。选错了会装不上或内核不匹配。

## 四、安装（AC2100 实操）

```sh
# 1) 装 nftables 队列依赖（UA2F 透明模式必需）
opkg update                                    # apk 系改用 apk update
opkg install kmod-nft-queue kmod-nft-tproxy    # apk 系改用 apk add ...

# 2) 把下载好的包传到路由器（在电脑上执行）
#    scp ua2f_3.7.0-r1_mipsel_24kc.ipk root@192.168.1.1:/tmp/

# 3) 在路由器上安装
opkg install /tmp/ua2f_3.7.0-r1_mipsel_24kc.ipk

# 4) 确认二进制和 init 脚本到位
which ua2f
/etc/init.d/ua2f status
```

也可以用 LuCI：**系统 → 软件包 → 上传软件包**，装完退出重登，菜单里出现「服务 → UA2F」。

---

## 五、一键配置（针对"多设备被检测"调优）

把本仓库的 `scripts/ac2100-setup.sh` 传到路由器后执行：

```sh
# iPhone 人格（TTL 64）—— 如果你平时用手机认证上网，选这个
sh /root/ac2100-setup.sh iphone

# 或者 Windows 人格（TTL 128）
sh /root/ac2100-setup.sh windows
```

脚本做的事（你也可以手动等价执行）：

```sh
uci set ua2f.enabled.enabled='1'
uci set ua2f.main.server_mode='TPROXY'    # 不依赖 Clash；不通再换 REDIRECT
uci set ua2f.main.bind='0.0.0.0'
uci set ua2f.main.port='1080'
uci set ua2f.main.rewrite_mode='RULE'     # 按规则改，给微信/Steam 放行
uci set ua2f.main.ua='<你的人格UA>'
uci set ua2f.main.l3_rewrite_ttl='1'
uci set ua2f.main.l3_rewrite_ttl_value='64'
uci set ua2f.main.l3_rewrite_tcpts='1'    # 顺手清 TCP 时间戳
uci set ua2f.main.l3_rewrite_ipid='1'
uci set ua2f.main.l3_rewrite_block_quic='0'  # 别开，会拖慢
uci set ua2f.main.l3_rewrite_bpf_offload='0' # MT7621 不要开 eBPF
uci commit ua2f
/etc/init.d/ua2f enable
/etc/init.d/ua2f restart
```

**AC2100 专属的几个"别开"：**

- `bpf-offload` / `l3_rewrite_bpf_offload`：MT7621 上收益低、风险高，**关**。
- `desync`（分片乱序）：AC2100 性能有限，且兼容性差，**先关**。确认学校有 DPI 再单独试。
- `mitm`：需要客户端装 CA，麻烦且容易全站报错，**关**。

## 六、针对"设备数被统计"的额外动作

统一 UA 是对付设备指纹的主招，但既然学校在**统计设备数**，顺手把这几个口子也堵上：

### 1. 微信 / QQ / 游戏等敏感客户端要放行

这些客户端对 UA 敏感，硬改会登录异常。`RULE` 模式下已经对
`MicroMessenger`、`Bilibili`、`Steam` 做了放行（见 `configs/ua2f-config.yaml`）。

### 2. 统一 NTP（时钟偏移检测的兜底）

```sh
sh /root/firewall-antidetect.sh install 64
```

同时在 LuCI「系统 → 系统 → 时间同步」里：勾选 NTP 客户端 + 勾选"作为 NTP 服务器"，
候选服务器填 `ntp1.aliyun.com` 等即可。

### 3. 让路由器自己别"露馅"

关闭路由器上不必要的外连（OpenWrt 定时任务、DDNS 等），
这些会用自己的 UA 发 HTTP 请求，虽然量小，但统计型检测偶尔会抓到。

### 4. 确认所有终端都走路由器

如果某台设备**同时**连了校园网 Wi-Fi 和你的路由器（比如手机双 WiFi、电脑插网线又连 WiFi），
那台设备会被学校看成两个客户端。这一点经常被忽略，值得先排查。

## 七、验证

```sh
# 路由器侧自检
sh /root/verify.sh

# 抓包看 TTL 是否稳定为 64（不该出现 63）
tcpdump -i br-lan -vv -c 20 'tcp and port 80'
```

然后在内网设备（**关掉 VPN**）打开 <http://ua-check.stagoh.com>，
确认显示的 UA 就是你在 `ua2f.main.ua` 里填的那一个。

最关键的验证是**实际使用**：让多台设备同时上网、看视频、刷手机，观察是否还会被断。
如果单设备正常、多设备仍然被断，把 `docs/05-验证与排错.md` 的排查项过一遍，
重点怀疑：有设备走了双重网络、有客户端绕过了路由器、或学校用的是 DPI（这时才考虑开 Desync
或上 Clash 加密代理）。

---

## 八、回滚

```sh
/etc/init.d/ua2f stop
/etc/init.d/ua2f disable
sh /root/firewall-antidetect.sh uninstall
```

装包前建议先备份：`uci export ua2f > /root/ua2f.bak`（如果之前配置过）。
